# PingPong Frontend

Messenger in the style of Discord.

## Stack

React 19, TypeScript, Vite

## Getting started

```bash
npm install
npm run dev          # http://localhost:5173
```

## Scripts

| Command          | Description      |
| ---------------- | ---------------- |
| `npm run dev`    | dev server       |
| `npm run build`  | production build |
| `npm run lint`   | ESLint           |
| `npm run format` | Prettier         |
